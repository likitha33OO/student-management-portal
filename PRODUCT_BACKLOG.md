# Product Backlog — Student Management Portal

| ID | User story | Priority | Acceptance criteria |
|---|---|---|---|
| US01 | As a user, I want a Home page to understand the portal. | High | Home page opens and links to key pages. |
| US02 | As a user, I want an About page to learn about the portal. | Medium | About page explains the purpose and objectives. |
| US03 | As a student, I want to enter my details in a registration form. | High | Form has name, ID, email, department and year fields. |
| US04 | As a student, I want to view available courses. | High | Courses page lists course names and descriptions. |
| US05 | As a user, I want a Contact page with contact information. | Medium | Contact details and a message form are displayed. |
| US06 | As a user, I want navigation between all pages. | High | Main navigation links open the correct HTML pages. |
| US07 | As a user, I want a responsive layout. | Medium | Layout adapts to mobile and desktop screen widths. |
| US08 | As a developer, I want to maintain source control. | High | Work is committed and pushed to GitHub. |
