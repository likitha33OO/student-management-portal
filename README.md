# Student Management Portal

**Course:** 26CS102 – Foundation of Full Stack  
**Project:** Student Management Portal  
**Sprint:** Sprint 1

## Project description
A static multi-page website built with HTML5 and CSS. It demonstrates a Home page, About page, Student Registration page, Courses page, and Contact page.

## Pages
- `index.html` — Home
- `about.html` — About
- `registration.html` — Student Registration
- `courses.html` — Courses
- `contact.html` — Contact
- `style.css` — Shared styling for all pages

## How to run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Use the navigation menu to open the other pages.

## Important limitation
This is a static front-end project. Registration details and contact messages are not saved or sent to a server. A backend and database would be required for that functionality.
